PATTERN MAP · 句型地图

把语法变成可复用的积木。

01

N은/는 N이에요/예요

N 是 N

有收音用 이에요；无收音用 예요。은/는 标记当前话题。

저는 중국 사람이에요.
학생이에요 / 의사예요
02

N이/가 있어요

有 N / N 在

有收音用 이；无收音用 가。있어요 表示存在。

책이 있어요.
없어요 是反义：책이 없어요
03

N을/를 V

动作对象是 N

有收音用 을；无收音用 를。把它想成动作箭头。

한국어를 공부해요.
책을 읽어요 / 커피를 마셔요
04

N이/가 아니에요

不是 N

把 아니에요 作为一个整体记。

저는 의사가 아니에요.
학생이에요 ↔ 학생이 아니에요
05

N도

N 也……

도 直接替换主题、主语或宾语助词。

저도 학생이에요.
相同情况的追加
06

N의 N

N 的 N

의 表示所属；저의 常缩成 제。

이것은 제 책이에요.
저의→제 / 나의→내
