# 塔罗学习小站

一个纯本地、零依赖的塔罗学习网站，部署在 GitHub Pages 子目录下。

## 访问地址

**https://cocoogaoo.github.io/tarot/**

## 功能

- 🃏 **牌库**：78 张牌可翻。点任意一张看牌义、讲解、与其他牌的关系、协助记忆口诀、🔄 逆位含义、四元素、星座对应、星骰补充
- ✍ **每日练习**：经典两张牌组合解读 + 随机抽两张自动生成解读示例
- 🔮 **占卜**：YES/NO 模式 + 三张牌阵（过去-现在-未来）模式
- 🏆 **成就**：学习进度 + 徽章体系

## 技术说明

- 单文件 `index.html`，所有数据内联，无需构建、无需外部资源
- 学习进度存浏览器 `localStorage`，仅本机可见，不上传
- 配色：深夜蓝 + 雾紫 + 月光金

## 本地预览

直接双击 `index.html` 用浏览器打开即可，或：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080/tarot/
```

## 数据来源

塔罗牌义、四元素、星座对应、星骰映射采用黄金黎明/托特体系的塔罗-占星标准对应（公认体系）。
